# Wisp

WhatsApp conversations, without the language barrier.

Wisp is a desktop companion for WhatsApp that translates conversations using your existing ChatGPT subscription.

[![Wisp demo — fictional conversation](docs/media/demo.gif)](docs/media/demo.mp4)

- Read translated messages inline.
- Write in your language and preview replies before sending.
- Translate voice notes, with audio transcribed on your device.
- Choose your ChatGPT model and customize languages and tone for each chat.

Connect WhatsApp and an [eligible ChatGPT subscription](https://developers.openai.com/siwc/quickstart), then turn on translation for a chat. Wisp is free, with no API key or separate API billing setup. Translation usage counts toward your ChatGPT plan.

Available for **macOS 14+** and **Windows x64**. Windows support is experimental.
